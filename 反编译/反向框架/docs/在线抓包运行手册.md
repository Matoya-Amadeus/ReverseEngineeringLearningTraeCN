Scope: <CONTENTS_ROOT>/反编译/反向框架

## Goal
Replace bootstrap-only live fingerprints with real HAR-based captures until real coverage reaches 9/9.

## Current Baseline
- Total routes: 9
- Real covered: 1
- Bootstrap only: 8
- Strict real quality gate target: `TRAE_AUTH_REAL_LIVE_COVERAGE_MIN=1`

## Input Placement
Put one or more real HAR files under `Contents` (recommended under `docs/`):
- `<CONTENTS_ROOT>/反编译/反向框架/docs/*.har`

The batch script auto-discovers the newest `.har` under `docs/` (recursive, max depth 6), unless `TRAE_AUTH_REAL_HAR_FILE` is explicitly set.

## One-Click Flow
Double-click:
- `<CONTENTS_ROOT>/反编译/反向框架/launcher/promote-real-capture.command`

Equivalent CLI:
```bash
cd "<CONTENTS_ROOT>/反编译/反向框架"
TRAE_AUTH_REQUIRE_REAL_HAR=1 \
TRAE_AUTH_REQUIRE_REAL_LIVE_COVERAGE=1 \
TRAE_AUTH_REAL_LIVE_COVERAGE_MIN=1 \
TRAE_AUTH_AUTO_DISCOVER_REAL_HAR=1 \
node replay/promote-real-capture-batch.mjs
node tests/auth/run-real-live-quality-strict-check.mjs
```

## Expected Outputs
- `docs/provider-fingerprints.live.real.in.jsonl` updated
- `docs/provider-fingerprints.live.jsonl` updated (bootstrap rows replaced route-by-route)
- `docs/Provider字段证据差异.md` refreshed
- `docs/真实抓包待办清单.md` refreshed
- Strict check passes when real coverage reaches `9/9`

## Failure Quick Triage
1. `REAL_BATCH_FAIL real HAR not found`:
- No HAR found in auto-discovery scope.
- Put HAR under `docs/` or set `TRAE_AUTH_REAL_HAR_FILE` explicitly.

2. `LIVE_QUALITY_FAIL ... below min 1`:
- Real capture coverage still below 100%.
- Continue importing more provider/route HAR samples; re-run one-click flow.

3. `MATRIX_FAIL` / `EVIDENCE_FAIL` permission:
- Ensure command runs with write permission to `Contents`.

## Completion Definition
This runbook is complete when:
- `真实抓包待办清单.md` shows `Bootstrap Only: 0`
- `tests/auth/run-real-live-quality-strict-check.mjs` exits 0
