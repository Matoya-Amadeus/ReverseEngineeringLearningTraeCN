## 核心模块说明

### 1. ai-agent (AI 代理核心)
- **语言**: Rust
- **功能**: AI 对话/推理核心
- **特点**: 使用 tokio-tungstenite 进行 WebSocket 通信
- **规模**: 224,413 函数

### 2. ckg (代码知识图谱)
- **语言**: Go 1.24.3
- **功能**: 代码索引和语义搜索
- **特点**: 代码理解核心
- **规模**: 12,966 函数

### 3. electron-core (Electron 框架)
- **语言**: C++
- **功能**: 应用程序框架
- **规模**: 413,334 函数

## 使用说明

### 搜索反编译代码
```bash
# 搜索特定函数
grep -n "function_name" src/*/*_FULL.c

# 搜索字符串
grep -r "search_term" src/
```
